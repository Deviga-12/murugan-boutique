 🧵 Murugan Boutique Web Application
📌 About the Project

Murugan Boutique is a web-based tailoring application developed to simplify customer interaction and service booking for a boutique business.

This application allows users to easily explore tailoring services, book stitching orders, and send inquiries through a contact form. All user data is securely stored and managed using a MySQL database.

The project is built using Python Flask for backend development and follows a structured approach with templates and static files for scalability and maintainability.
 🎯 Key Features

- 🧾 Online Booking System for tailoring services  
- 📩 Contact Form with database storage  
- 📊 Admin Dashboard to view bookings and messages  
- 🔄 Dynamic form handling using Flask (GET & POST)  
- 💾 MySQL database integration  
- 🎨 Clean and user-friendly interface  
 🛠️ Technologies Used

- Python  
- Flask  
- MySQL  
- HTML  
- CSS  
🚀 Purpose

The main goal of this project is to understand real-world backend development concepts such as database integration, form handling, and building a complete web application using Flask.
